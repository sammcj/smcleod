## Using the colours

The tab yellow marks the focused window. Unfocused windows mute it, so the one taking keyboard input stands out without a heavier border.

The accent colour is for links and focus rings. Both values keep at least 4.5:1 contrast against the reading background in their scheme.

Dark values are a step lighter so they read at the same weight on a dark background.

## Notes

Contrast was checked with the WCAG 2 formula. Links inside a page, like the one above, scroll this window rather than the page behind it.
